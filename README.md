# Cross-device workflow hub

Open this repository on any device: https://github.com/ucedric29/ucedric29

This hub stores portable instructions and task handoffs. It does not automatically sync device files, chat history, credentials, or installed MCP servers. This repository may be public: keep private work and credentials elsewhere.

## Continue on another device

1. Sign in to the same AI account and GitHub account.
2. Open this repository in a cloud coding session, or clone it locally.
3. Ask the assistant: “Read AGENTS.md and HANDOFF.md, check available tools, then continue the next task.”
4. For an external service, use its account connection settings. Local MCP servers need a running host; a disconnected device cannot provide them.

See [HANDOFF.md](HANDOFF.md) for task continuity and [CONNECTIONS.md](CONNECTIONS.md) for the connection checklist.
