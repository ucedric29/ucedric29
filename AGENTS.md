# Workflow continuity

Use the existing checkout. Do not create a worktree unless requested.
Read HANDOFF.md before working. Discover the tools actually available in the current session; do not assume integrations transfer between devices.
Proceed with authorized useful work and reasonable defaults. Ask only when a missing decision or access blocks progress.
Before finishing, update HANDOFF.md with completed work, next actions, verification results, and blockers. Keep entries concise and factual.
Save project work in its own repository. Commit and push authorized changes so another device can retrieve them; report push failures plainly.
Never put passwords, tokens, private keys, credential files, or private service URLs in this repository. Use account connection settings or a secret manager.
Do not claim a local device, MCP server, or external account was backed up or connected without verification.
This repository may be public. Keep private task details in a private repository or account-backed workspace.
